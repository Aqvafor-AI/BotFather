
# Телеграм-бот для квиза

Это проект телеграм-бота, который проводит квиз на тему Python. Бот задает пользователю вопросы, и он должен выбрать правильный вариант ответа. После завершения квиза бот выводит результат и сообщает, правильно ли были отвечены все вопросы.

## Описание

Телеграм-бот использует библиотеку `aiogram` для работы с Telegram API и `aiosqlite` для хранения состояния пользователя в базе данных SQLite. Этот проект может быть использован для обучения и самоконтроля в изучении языка Python.

## Команды бота

- `/start` — Запуск бота, приветственное сообщение и кнопка для начала игры.
- "Начать игру" — Начало квиза, вывод первого вопроса.

## Установка и запуск

1. Клонируйте репозиторий на ваш локальный компьютер:
   ```bash
   git clone https://github.com/yourusername/your-repo.git
   cd your-repo
   ```

2. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `config.py` в корневой директории проекта и добавьте туда ваш **API токен** бота, который вы получите от [BotFather](https://core.telegram.org/bots#botfather):
   ```python
   # config.py
   API_TOKEN = 'your-telegram-bot-api-token'
   DB_NAME = 'quiz_bot.db'
   ```

4. Запустите бота:
   ```bash
   python bot.py
   ```

## Структура проекта

Проект состоит из нескольких файлов:

- **`bot.py`** — основной файл, который запускает бота.
- **`config.py`** — файл с настройками, в котором хранится токен бота и название базы данных.
- **`db.py`** — модуль для работы с базой данных (SQLite), который управляет состоянием пользователя.
- **`quiz.py`** — файл с данными квиза (вопросами, вариантами ответов и логикой создания клавиатуры).
- **`handlers.py`** — обработчики команд и колбеков.
- **`README.md`** — описание проекта (этот файл).

## Пример использования

1. Запустите бота и нажмите кнопку "Начать игру".
2. Бот будет задавать вам вопросы с несколькими вариантами ответов.
3. После завершения квиза бот сообщит вам, верно ли были даны ответы.

## Статистика

После прохождения квиза, бот сохраняет состояние пользователя и выводит информацию о его результате. На данный момент результат хранится только в базе данных для каждого пользователя.

## Важные замечания

- Для работы бота необходимы библиотеки `aiogram` и `aiosqlite`. Они могут быть установлены с помощью команды:
  ```bash
  pip install aiogram aiosqlite
  ```

- База данных создается автоматически при запуске бота и хранит информацию о текущем вопросе для каждого пользователя.
